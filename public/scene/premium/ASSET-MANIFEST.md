# Summon World Premium Gateway Assets

Purpose: cinematic gateway transition for `/enter`.

## Project-generated assets

- `portal-depth.png` - custom generated portal interior / open-gate depth plate.
- `portal-bloom.png` - transparent bloom overlay.
- `fog-veil.png` - transparent atmospheric fog overlay.
- `gold-seam.png` - transparent vertical seam flash.
- `rune-ring.png` - transparent restrained arcane ring overlay.
- `film-grain.png` - transparent fine grain overlay.

## Design usage

Use the generated portal plate as the main visual reveal. Use the Kenney particles sparingly as atmospheric accents only; the visual system should feel cinematic and restrained, not arcade-like.
