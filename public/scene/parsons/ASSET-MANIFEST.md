# Parsons-Grade Gateway Art Direction Assets

Purpose: replace the earlier patched/collaged door animation with unified full-frame key art.

## Assets

- `closed-gateway.png` - full-screen 16:9 sealed gateway plate for `/enter`.
- `open-threshold.png` - full-screen 16:9 opened threshold plate for the click transition.

## Generation Direction

Both images were generated as custom project-bound raster assets with the same art direction:
restrained monumental architecture, obsidian/charcoal surfaces, antique gold linework, muted violet light, large negative space, cinematic product-level composition, no text, no logos, no characters.

## Usage Rule

Do not crop pieces of these images into fake physical doors. Use them as whole-frame states and transition between them with opacity, scale, bloom, and fog. The premium feel comes from consistent full-frame composition rather than mechanical CSS slicing.
