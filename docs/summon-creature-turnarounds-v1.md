# Three-view / expression reference sheets for first career creatures

These are **2D generated modeling references**, NOT production 3D topology,
UVs, fully orthographic measurements, verified anatomy, skeletal rigs or
animation. They follow the three 3D-style base illustrations developed in
the separate first-nine-render art PR and are suitable for a human modeling
brief, subject to manual geometry/continuity review.

The three original landscape reference sheets are preserved as optimized
WebP under `public/storybook-premium/summons/references/`:

Each sheet includes front, profile, back and three expression concepts.
These must NOT be treated as independently true orthographic renderings:
modelers should reconcile differences and create real orthographic turntables.

## Preserve species identity in actual 3D modeling

- **Circuitling**: broad otter face, four legs, glass-finned ears, segmented
  polygon tail. Confirm the tail in rear and side views matches the front.
- **Stridekin**: athletic hare silhouette, disproportionately long ears,
  springy legs, coral loop tail. Do not replace the ribbon with extra limbs.
- **Mossprite**: four deer hooves, cream muzzle, gentle eyes, tree-sprout
  antlers, moss mane. Maintain correct hoof count and antler branching.

## Next real 3D deliverables

1. Sculpt original watertight models in a 3D package using these visual guides.
2. Review orthographic turntable renders for facial, ear, hoof and limb geometry.
3. UV unwrap, texture, rig and create idle/gesture/evolution animations.
